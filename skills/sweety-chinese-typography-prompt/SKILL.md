# 中文字体提示词

这个 skill 用于给中文文字类图像写提示词。它解决的是“字怎么被设计出来”，不是“标题写什么”。

适用场景：中文字体图、封面大字、海报标题字、banner 字、短视频缩略图字、小红书首图字、公众号封面字、Logo 感字形、书法题字、儿童绘本标题、涂鸦字、像素字、霓虹招牌字、电商促销字。

## 核心判断

不要把“好看”“高级”“有设计感”当作提示词。它们是结果，不是可执行指令。

公众号封面、短视频缩略图、小红书首图等需要独立吸引点击的图，封面字必须像可信标题一样讲清事情。主字不能只有情绪口号或孤立动作，例如只写“先别海投”“别堆课程”“别焦虑”不合格；至少要写出对象/场景 + 动作/判断，例如“被裁后，先别海投”“校招没回应，别堆课程”。如果短主字必须保留，副字必须补足对象、场景和读者收益。

中文字体提示词默认公式：

```text
“文字内容”，字体类型，笔画/结构/重心/边缘描述；加入字效/材质/光影/背景，整体气质。
```

最小合格 prompt 必须包含：

| 字段 | 说明 |
|------|------|
| 文字内容 | 必须用引号明确，要求保持中文准确可读 |
| 字体类型 | 如极简品牌体、粗黑封面体、儿童绘本蜡笔体、东方瘦金标题体 |
| 笔画 | 粗细、直曲、连断、提按、飞白、颗粒、切角、膨胀等 |
| 结构 | 紧凑/舒展、方正/高挑/宽扁、重组/错位/模块化 |
| 重心 | 低重心、竖向拉伸、横向延展、稳定居中、倾斜前冲等 |
| 边缘 | 锋利、圆润、磨损、纸纤维、喷漆颗粒、像素锯齿等 |
| 字效/材质 | 贴纸、金属、玻璃、油墨、蜡笔、剪纸、霓虹、像素、木刻等 |
| 光影/背景 | 纯字体、黑底白字、白底黑字、纸张、墙面、UI、海报背景等 |
| 整体气质 | 商业可信、童真、潮流、复古、科技、东方、街头、强观点等 |

## 工作流

1. 先确认最终交付物是不是静态位图。若是 PNG/JPG/WebP 等图片资产，仍遵守全局图像生成规则：默认用 Codex 内置图像生成能力，不用 HTML/CSS/SVG/Canvas/Pillow/截图合成替代。
2. 明确文字内容。中文必须逐字确认；如果用户没给具体文字，先问最小问题。
3. 判断使用场景：封面点击、品牌 Logo 感、知识卡标题、儿童绘本、生活方式、科技产品、复古招牌、书法题字等。
4. 若是封面、缩略图或首图，先做“封面契约检查”：脱离正文标题，读者能不能 3 秒看懂写谁、发生什么、该做什么。看不懂就补主字或副字。
5. 从场景选择字体方向。可用方向见 [references/style-directions.md](references/style-directions.md)。
6. 按公式写出完整 prompt，避免只有风格名。
7. 加入中文可读性约束：保持文字准确、清楚可读，不要乱码、不要多字少字、不要拼音替代、不要伪文字。
8. 如果是正式封面或平台发布图，同时检查是否需要 `sweety-trustworthy-title` 先确定标题内容，再用本 skill 设计字形。

## 输出模板

用户要“直接给 prompt”时：

```markdown
“文字内容”，字体类型，笔画描述，结构/重心描述，边缘/材质描述；背景和光影描述，整体气质。保持中文准确可读，不要乱码、多字、少字或伪文字。
```

用户要多个方向时：

```markdown
## 方向 1：名称
Prompt：...
适合：...

## 方向 2：名称
Prompt：...
适合：...
```

用户要接入生图队列时，把 prompt 写成可直接交给图像生成器的一段完整描述，不输出分析过程。

## 常用组合

| 场景 | 推荐方向 |
|------|----------|
| 公众号封面、短视频缩略图 | 爆款封面体、强观点夸张体、清晰粗黑标题体 |
| 知识卡、课程封面 | 现代知识字、模块课程标题体、理性细线体 |
| 小红书生活方式 | 清爽留白体、温柔细线体、成长笔记体 |
| 儿童绘本、亲子内容 | 儿童绘本蜡笔体、童趣涂画体、手剪纸片拼贴体 |
| 科技/AI/工具 | 几何科技体、未来细线体、赛博断裂体 |
| 东方/国风 | 东方瘦金标题体、国风牌匾体、潮流篆意体 |
| 潮流/街头 | 潮流品牌字、街头喷漆体、泡泡潮牌涂鸦体 |

## 硬性边界

- 不输出只有“帮我生成 XX 几个字”的 prompt。
- 不把“好看、高级、有设计感、爆款感”单独当成字体描述。
- 不输出脱离标题后看不懂的封面字。公众号封面主字必须包含对象/场景或由副字补齐，例如“被裁后，先别海投”优于“先别海投”。
- 不为了炫技牺牲中文可读性。
- 不默认生成复杂背景；若用户要纯字体设计，明确写“纯字体设计，无装饰”。
- 不把中文字体图任务改成 HTML、SVG、Canvas、Pillow 或截图合成，除非用户明确要求结构化矢量或可编辑代码资产。
- 不调用需要 `OPENAI_API_KEY` 的脚本或 API 作为默认生成路径。
