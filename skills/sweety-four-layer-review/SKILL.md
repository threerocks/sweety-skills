# 四层自检终审

写作流水线的最后一棒：
```
作者风格 skill（初稿）→ Humanizer-zh（通用去 AI 味）→ 【本 skill：四层自检终审】
```

它的角色是**质检员**，不是作者。它只做两件事：**逐层判定**，把不过关的问题**指回上游 skill 去修**（AI 腔回 `sweety-humanizer-zh`，像不像本人回 `sweety-liulei-writer`）。它**不重写正文、不发明新规则**。

设计理念学软件测试金字塔：从最硬的事实层，到最主观的人格层，越往后越主观。**顺序即优先级——上一层不过，先修上一层。**

---

## L1 · 事实与逻辑硬伤（最硬，零容忍）

这一层查的是"硬错"，任一命中即**不可定稿**。

- 有没有**编造**的事实、数字、经历、案例、出处、人名、检测结果？（尤其警惕：上游为了"像人""有细节"而虚构的具体）
- 有没有把**猜测当事实**？该标"不确定/没查到"的地方标了吗？
- 有没有**逻辑跳跃**：前句 A、后句突然 B，中间缺桥？
- 有没有**因果硬伤**：只有相关说成因果、孤例当规律、把最近发生的当原因？
- 关键判断有没有**起码的支撑**（证据/来源/经历/参数），还是只有论断？

**通过标准**：无编造，无把猜测当事实，关键因果有机制或已标边界。
**不过怎么办**：标出每一处硬错，退回作者补材料或改判断——**这一层不修，后面三层都白做**。

## L2 · AI 腔残留（验证 Humanizer 是否到位）

Humanizer 跑过一遍后，这层做**复扫**，确认通用 AI 味清干净了：

- 中文 AI 黑话（赋能/抓手/闭环/底层逻辑/颗粒度/护城河/链路/心智…）还有没有漏网？
- 教科书开头（"在当今……时代""随着……发展"）/ 万能升华结尾（"共同期待""时代召唤""提供启发"）？
- 三段式硬凑、否定式排比（"不是……而是……"）、-ing 式肤浅分析（一串"……着"挂句尾）？
- 报幕（"接下来让我们""下面我来科普"）、装腔套话（"说到底/本质上/真正的问题是"后面却没干货）、小标题下重复标题的废话？
- 谄媚腔、协作对话痕迹（"希望对你有帮助"）？

**通过标准**：上述零残留（作者**故意**的口语/毛边/口癖不算 AI 腔，不要误杀）。
**不过怎么办**：把残留清单交回 `sweety-humanizer-zh` 再清一遍，别在终审里手改。

## L3 · 节奏是否单调

- 连续 3 句以上句长接近？（机械节奏，打散一句）
- 段落是不是都一个长度、像提纲展开？
- 通篇句号化、没有长短交错、没有一句话独立成段的停顿？
- 有没有读起来像"可引用金句"的句子？（重写成落在具体事上的话）
- 该快的地方（冲突/判断）有没有变短，该缓的地方（讲清楚一件事）有没有铺开？

**通过标准**：句长长短交错，段落有疏密，关键判断有停顿重量。
**不过怎么办**：标出节奏呆板的段落，回上游调整。

## L4 · 还像不像作者本人（最主观，人格层）

不逐条打钩，而是以读者视角通读全文，回答一个核心问题：

> **"这是一个具体的人（开过店、踩过坑、算着成本、有明确好恶）在跟我说话，还是一个 AI 在输出正确信息？"**

具体感知维度：
- **替换测试**：把文中的作品名、产品名、物件名换掉，这段还成立、任何公众号都写得出吗？是 = 没有作者阻力，不像本人。
- **作者摩擦**：有没有至少一两处"我不信什么/我不建议什么/我觉得哪里成本不值/哪里新手会误判"？
- **体感而非知识**：情绪是体感（"我当时就……""烦"）还是知识性描述（"我感到很震撼"）？
- **姿态**：是同路人在提醒，还是导师在训、品牌在营销、客服在哄？
- **落地而非升华**：结尾是给保守建议/适用范围/"你觉得呢"，还是拔高？

**通过标准**：整体读下来"是这个人在说话"。
**不过怎么办**：把"闻着像 AI / 不像本人"的段落挑出来，交回 `sweety-liulei-writer`，想象作者本人会怎么说，重写。

## 质检报告格式

四层走完，输出一份简洁报告：

```
## 终审质检报告

L1 事实与逻辑    ✅/❌
  - 编造：X 处（位置…）
  - 猜测当事实：X 处
  - 逻辑/因果硬伤：X 处

L2 AI 腔残留     ✅/❌
  - 黑话/套话/报幕/三段式…：X 处（列出）

L3 节奏          ✅/❌
  - 单调段落：位置…

L4 像不像本人    ✅/❌
  - 替换测试是否通过 / 作者摩擦够不够 / 姿态对不对（具体段落…）

判定：可定稿 / 需返修 / 只能算草稿
返修去向：L1 退作者补料 · L2 退 Humanizer · L3+L4 退 sweety-liulei-writer
修复优先级：[最该先改的 1-3 个具体问题]
```

**判定规则**：
- L1 有任一 ❌ → 直接判"只能算草稿"，不往下走。
- L1 过、L2/L3/L4 有 ❌ → "需返修"，按去向退回对应 skill。
- 四层全 ✅ → "可定稿"（仍交人工终校，不承诺传播效果或检测结果）。

**收敛终止**：同一篇最多回流 2-3 轮；第 3 轮仍有 ❌，标 `[需人工]` 移交，不无限自动改。

---

## 用法

- 输入一篇成稿（最好已过 Humanizer），直接跑四层、出报告。
- 只要判定不是"可定稿"，不要对外称"终稿"。
- 本 skill 是 sweety 写作流水线的收尾，也可单独用于任何中文成稿的发布前把关（L4 的"作者本人"换成该文的目标作者即可）。
