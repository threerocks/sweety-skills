# 风格系统：Pinterest 与 VHTC

本文件只记录可迁移的风格原则，不复制具体页面内容。

## Pinterest 式视觉

适用场景：封面、社媒图、灵感图、生活方式图、产品氛围图、情绪板、系列选题首图。

核心判断：

- Pinterest 的底层不是单张“完美图片”，而是“可保存、可归类、可继续计划”的视觉线索。
- 画面应有明确的收藏理由：配色、对象、场景、姿态、材料、穿搭、步骤、主题词或可复用灵感。
- 视觉第一眼要强，但不要像广告硬卖；更像“我想把这个放进某个 board 里”。

写作策略：

- 把图像写成一个小型 moodboard：主体 1 个，辅助线索 3-5 个，色彩锚点 2-3 个。
- 允许非中心化构图、裁切、局部特写、拼贴感、桌面陈列、真实生活角落。
- 关键词要像用户会搜索和收藏的词，而不是品牌自夸词。
- 保留轻微真实痕迹：材质磨损、自然阴影、手工摆放的不齐、背景中合理但不抢戏的小物件。
- 若有文字，倾向短标题、清晰主题词、少量标签；避免长段说明压住视觉。

常用 brief 片段：

- “像被用户收藏进灵感板的一张图，而不是电商广告硬照。”
- “画面里有 3 个可被单独保存的视觉线索：颜色、材质、场景动作。”
- “不要中心对称的模板海报，保留一点真实拍摄的裁切和呼吸感。”
- “让标题像搜索词，而不是宣传口号。”

## VHTC 式教育图解

适用场景：医学/解剖图、学习卡、考试复习图、概念解释图、公众号科普配图、教学 poster。

核心判断：

- VHTC 的底层是“学生能快速理解和复习”，不是艺术表达。
- 好图解要把复杂对象分层：标题、主体图、标注线、局部放大、功能说明、总结表。
- 信息密度可以高，但阅读路径必须清楚。

写作策略：

- 先定义学习目标：观众看完必须记住哪 3-5 个结构或关系。
- 主体保持解剖/结构准确，标注线干净，标签靠近对应部位，避免交叉和遮挡。
- 使用教育图常见的白底、浅色底、网格纸、手绘线稿、局部放大圆窗、彩色分层。
- 标题醒目但不花哨；正文标签用短词，不在图内堆长解释。
- 对医学/解剖内容必须要求结构准确、比例合理、标注拼写正确；不确定时提示需要专业校对。

常用 brief 片段：

- “以学生复习为目标，优先清晰标注和结构准确，不追求戏剧化光影。”
- “主体居中，周围环绕短标签，绿色或深色引导线连接到具体结构。”
- “加入一个局部放大窗口解释内部结构，放大区域与原图有明确连接。”
- “所有标签必须可读、拼写正确、与结构位置一致。”

## 组合策略

Pinterest 提供“可保存的视觉吸引力”，VHTC 提供“可学习的信息层级”。两者组合时：

- 第一眼用 Pinterest：干净、可收藏、色彩有记忆点。
- 第二眼用 VHTC：标题明确、标注准确、阅读路径稳定。
- 不要让装饰压过知识；也不要让知识图变成枯燥截图。

组合 brief：

```markdown
做一张可被保存到 Pinterest 灵感板的教育图解：第一眼是干净、有收藏感的视觉卡片；细看能像 VHTC 学习图一样读出结构、标签和关系。白底或浅色网格纸，主体清晰，短标签环绕，局部放大窗口解释关键结构，保留自然手绘/编辑痕迹，避免过度电影感和模板化 AI 光泽。
```
