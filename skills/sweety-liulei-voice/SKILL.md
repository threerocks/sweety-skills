# liulei 句段级口吻（voice）

这个 skill 是一个**口吻转换层**：内容（事实、观点、要点）来自用户，它只负责"liulei 本人会怎么说这句话"。不选题、不出观点、不搭文章结构、不起标题——那些是 `sweety-liulei-writer` 的领地。

像不像的载荷分布：**七成在句式与局部逻辑（`references/patterns.md`），三成在选词（`references/lexicon.md`）；负指纹（`references/negative-list.md`）负责不露馅。** 三个文件执行时全部要读。

---

## 1 输出合同（三种模式）

| 模式 | 输入 | 输出 |
|---|---|---|
| ① 转换（默认） | 一句话 / 一段话（≤3 段） | 同样意思的 liulei 口吻版本 |
| ② 代拟 | 一个意思 / 几个要点 | liulei 口吻的一句或一段 |
| ③ 校验 | 一句话 / 一段话 | 逐处指出哪里不像 + 怎么改（不重写全文） |

硬约束：

- **观点与事实永远来自用户**。转换不得增删事实、不得改变判断强度与立场；原文立场明显不像 liulei（如无边界的吹捧、贩卖焦虑）时，输出旁**标注提醒**，不伪造他的态度。
- 超过 3 段的整篇任务，指回 `sweety-liulei-writer`，不要在本 skill 里放大。
- **整句重写，不是换词**。把意思拆出来用他的句式重说，禁止在原句上做同义词替换——替换出来的是"贴了皮的原句"。

## 2 第一步永远是定语域

语域决定开哪组词、用哪组装置。判定不了就问用户一句，不要混用。

| 语域 | 判定信号 | 词库组 | 主装置（patterns） |
|---|---|---|---|
| 课程教学 | 讲课稿、专栏、教程、给学员解释概念 | §9 + 全部★ | B16 类比、B17 概念三步、B18 推论链、B2 设问 |
| 口播 | 要念出来的稿：直播、视频口播 | §10 + 全部★ | B6 铺开、A 口播节奏、B2 |
| 技术博客 | 方案、复盘、源码分析，读者是同行 | §11 + 全部★ | B4 选型、B11 就不X了、B7 数字 |
| 生活复盘 | 年终总结、个人经历、随笔 | §12 + 全部★ | B12 滑出、B13 补刀、B14 那时候排比、B5 重复 |
| 水族问答 | 鱼缸水草、答客户问 | §13 + 全部★ | B1 定性先行、B5、开车类比 |

节奏跟语域走（patterns §A 的实测数字）：复盘/水族滚长句，课程稿短而清，口播中长连缀。**语域间的形态不得互串**——把课程稿写成滚长句、把复盘写出破折号，都是露馅。

## 3 执行流程

1. 定语域（上表）；模式①先读懂原文的意思和立场。
2. 读 `references/lexicon.md` 对应语域组 + `references/patterns.md` 装置表，选 1–2 个该语域主装置承重。
3. 按装置整句重写；判断句落在具体对象、数字、动作上（B7 是全语域铁律）。
4. 对 `references/negative-list.md` 扫一遍：零出现词、极低频伪指纹、语域错配、实体禁令。
5. 配额自检（见 §5），超了就删。

## 4 蒸馏排除项（写作时同样执行）

- **人名、地名、雇主、案例对象、账号名**：一律不得进新文本（negative-list §五）。
- **语料原文**：skill 文件只放蒸馏物（词条、频次、条件、装置形态、短语级签名件）；句级原文一律不入库，词条与装置的原句证据存本地档案（见 §7），要看证据去那里查。
- **文章结构**：标题、开头模板、章节骨架、结尾模板不在本 skill 范围。课程结尾的"欢迎留言/下节课再见"属章节模板，除非用户点名要，否则不产出。
- **语料私人细节**：例句携带的经历、数字、产品、剧集引用不得复用。

## 5 配额律（防"演他"）

词库是调色盘不是配额，堆词=露馅：

- 一段：◆ 语域词 ≤2，▲ 低频特征词 ≤1，⚠ 词默认不用。
- 同一特征词一段 ≥2 次、或相邻两段重复同一 ▲ 词——删。
- "其实 / 我觉得 / 毕竟"不是他的标签，全语料低频，别靠它们撑人味。
- B5 重复、B14 排比：一段至多一处，全篇至多两处。
- 拿不准像不像时，**先检查句式和节奏，再检查用词**——载荷七成在前者。

## 6 检测边界（诚实条款）

按项目实测铁律：AI 检测判 token 指纹，**本 skill 转换出的句子无论多像，检测器仍判 AI**。所以：

- 本 skill 管"读者觉得像 liulei"，不管"检测器判人工"。
- 可直接使用的场景：评论、短帖、群聊回复、私信、内部文档、课程讲稿等不过检测的文本；正式档公众号流水线里 AI 被允许写的薄连接。
- 要过检测的正文：本 skill 的输出只作**提词参考**——作者照意思用自己的话重敲，真 token 是作者的。

## 7 语料与再蒸馏

当前词库与装置库来自六组语域语料约 25 万字（分组代号见 lexicon 频次记法）。语料构成、来源清单、清洗与隔离规则均记录在本地档案，不进公开仓库；近期语料与教学语料在结论冲突时优先。

再蒸馏 / 扩充语料时，运行 `learning/2026-09-01-corpus-mining/` 下的脚本（mine1/2 针对手写体语料组，mine3/4 针对教学语料组，verify_neg 核验排除表），新增语料先过来源清洗：剔除翻译与转载、标注语域与年代、可疑 AI 混写清单交用户确认。**语料句子与统计报告不入仓库**（含正文内容），只存本地 `~/.codex/writing-style/liulei/mining-2026-09-01/`，脚本可随时重算。**新语料权重高于旧语料；水族知识库未认证篇目仍只作事实资料。**

## 8 自检收尾

输出前逐条过：

1. 语域选对了吗？节奏形态（句长、逗号密度、破折号有无）符合该语域的实测数字吗？
2. 事实、数字、立场与输入完全一致吗？没有编造的经历或数据吗？
3. 承重的是句式装置还是堆词？删掉特征词后这段还像他吗（像=装置对了；不像=重写句式）？
4. negative-list 扫过了吗？有没有语域错配词、实体泄漏？
5. 配额超了吗？
6. 大声读一遍：这是那个"先看哪里会坏、给判断带前提、算着成本说话"的人在说，还是一个 AI 在演他？

改完仍拿不准，输出两版（保守版 / 特征更浓版）让用户选，并各标一句差异。
