# liulei 句段级词库（分级 · 六源实证 · 纯蒸馏物）

改写一句话、一段话时的取词依据。**词库是调色盘，不是配额**——每个词只在它的语域和条件下用，堆词=露馅。

**本文件只放蒸馏结果**：词条、频次、语域、使用条件。原文句子（例句、KWIC、语料数据）一律不入库——词条的原句证据在本地档案 `~/.codex/writing-style/liulei/mining-2026-09-01/`，用 `learning/2026-09-01-corpus-mining/` 的脚本可对全量语料重算复核。词条本体若为签名短语，短语即蒸馏物。

**频次记法**（语料构成不公开，代号只表示语域分组）

频次代号对应六组私有语料的语域分组：`课`＝教学专栏体（细分 课A / 课B 两组）、`播`＝口播体、`技`＝技术说明体、`复`＝个人复盘体、`水`＝水族问答体、`手`＝近期亲笔。全量约 25 万字。语料构成、清洗规则与每条词条的原句证据存本地档案 `~/.codex/writing-style/liulei/mining-2026-09-01/`，脚本可重算；教学与近期亲笔两组在结论冲突时优先。

**分级**

- ★ 核心词：跨语域稳定出现，可自然使用。
- ◆ 条件词：只在标注的语域用（语域定义见 SKILL.md）。
- ▲ 低频特征词：提气，但**每段最多 1 个**，两段不连用同一个。
- ⚠ 慎用词：真实存在但极易模仿过度，用前先问"此处非它不可吗"。

## 取词流程（写之前过一遍）

1. 定语域：课程教学 / 口播 / 技术博客 / 生活复盘 / 水族问答，只开对应的 ◆ 组（语域判定见 SKILL.md）。
2. 主干用 ★ 核心词自然写，**不数配额**。
3. 最多放 1–2 个 ◆ 语域词、至多 1 个 ▲ 低频词，⚠ 词默认不用。
4. 写完检查：同一特征词一段出现 ≥2 次，或一段挤了 ≥3 个 ▲/◆ 词——删到只剩最值的那个。
5. 对照 `negative-list.md` 扫一遍该语域的禁用表。
