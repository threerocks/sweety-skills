# liulei 句段级表达模式（局部逻辑 · 六源实证 · 纯蒸馏物）

管一句到三句之间怎么推进。**比词库更重要**：像不像，七成在这层，三成在选词。

**本文件只放装置的形态与判据，不放语料原句**。每个装置的原句证据在本地档案 `~/.codex/writing-style/liulei/mining-2026-09-01/`（KWIC 报告按装置可检索），入库的只有：装置形态、触发条件、语域、以及短语级签名件（短语即蒸馏物）。

---

## A 节奏的物理形态（实测数字）

| 指标 | 技术博客 | 生活复盘 | 课A | 课B | 口播转录 |
|---|---|---|---|---|---|
| 句均长度 | 36 字 | 41 字 | 40 字 | 35 字 | 50 字 |
| 句均逗号 | 1.2 | 2.5 | 1.2 | 0.9 | 1.6 |
| ≥80 字长句占比 | 7% | 12% | 7% | 4% | 13% |
| 单句最多逗号 | 14 | 22 | 7 | 7 | 7 |

写段落时照这个形态：

- **复盘/水族敢滚长**：情绪或叙事上来时一句连十几个分句滚完；**禁 staccato 短句排**——三五个字一句地切，是另一种工整，机器味更重。
- **课程稿短而清**：句子 30–40 字，一句一个信息点，句号密度高是正常形态；但也不切碎句。
- **口播稿滚中长**：一句 50 字上下，逗号连缀，一口气讲完一个意思再断。
- **句内允许漂题再绕回**（复盘/口播）：说着 A 突然漂到相邻的真实联想 B，插一句再回来；漂题必须是联想的自然流动，不是随机插入。

## B 局部逻辑装置（一至三句内的推进方式）

### B1 定性先行：一句拍板 → 理由/步骤 → 收口
第一句直接给定性判断，不铺垫；接着给可执行步骤或理由；用短词断掉退路收口。签名件：`没了。` `就对了` `当然可以，但是没有必要。`

### B2 自问自答 / 设问推进
抛一个问题马上自己答；答案句爱用现成的硬断言收。课程语域另有"代读者发问"变体：借"可能有朋友会问 / 很多同学会问"把疑问摆出来再拆。签名件：`那…呢，答案显然是否定的` `很简单，…`

### B3 括号三用法（全语域高频装置）
1. **补条件 / 补定义**：术语后括号给白话名，或数字后括号给取值依据。
2. **塞吐槽 / 真心话**：叙述场面话，括号里给真实动机。签名格式：`（翻译：X）`——庄谐反差自嘲专用。
3. **给免责 / 边界**：数据或建议后括号声明适用范围。签名件：`（仅供参考）`

### B4 选型叙事：要么…要么…最终没有一款…于是自己动手
枚举现有选项各自的死因（每个"要么"接一条具体缺陷）→ "最终没有一款符合要求" → "于是"自己写。评价自己的产出敢用"效果非常棒"级别的直白好评。

### B5 重复推进情绪（复/水专用）
同一个词连写两三遍把情绪顶上去。签名形态：`终于，终于，终于…` `很快的很快` `但是，但是` `至少至少`。一段最多一处，全篇最多两处。课程稿不用。

### B6 列举铺开不收口，用碎屑词收（复/播）
并列项直接铺，不做总结句；口语用"…啊、…啊、…啊"串起，收在 `balabala 就烦` `等等等` 这类碎屑词或一个直接后果上。不写"凡此种种，不一而足"式的书面收束。

### B7 数字精确癖（全语域铁律）
判断落在带单位的具体数上：月数、百分比、行数、价格、次数。宁可小而准，不用"显著提升/大幅优化"。数字与汉字之间加空格。冲突感靠数字对比自己长出来（前后两个数并置），不靠形容词。

### B8 让步—收窄：能用，但……
先承认对方 / 现实的合理部分（虽说 / 虽然 / 能用），紧跟一个收窄、代价或前提。签名件：`能用，但前提是…` 变体是双重否定降温：`也算很不错了`。

### B9 层层后撤（对自己的东西也降温）
给出自己的功能或方案 → 反手一句不推荐 → 给一条更省的路 → 最后仍留人工兜住。签名件：`但我却不推荐` `你仍然需要亲自检查` `一个小瑕疵`（小标题式认怂）。一个亮点三层后撤，可信度来源。

### B10 冷幽默：反差直译与江湖体（复/技/水）
三个签名装置：庄词谐用（拿佛家 / 武侠语汇说日常琐事）；传闻标 `据江湖消息`；亮利益立场自证清白（`还好我不是卖鱼的 ^_^`）。幽默永远贴着真实事实，不编段子。

### B11 "就不 X 了"+理由 收束（技/课）
主动收缩范围并给理由，把读者引到该去的地方。签名形态：`就不多说了` `就不贴出了，毕竟…` `就不再赘述` `不做过多介绍，请移步`。开场版：`因篇幅问题…后续会作为一个专题`。

### B12 句尾滑出（复盘专用，不升华收尾）
段落结尾不总结不升华，话说到位就放下。签名件：`，再说` `就这样吧` `…为止...` `持续观望` `嗯。`

### B13 半句自我修正 / 补刀
上一句说完，下一句立刻补一刀或补一证。三个起手：`可惜`（把刚说的好事打个折）、`但这才…呢`（把刚说的趋势泼冷水）、`没错，`（抢先确认读者的惊讶再加码）。

### B14 那时候排比（复盘专用，全篇至多一处）
骨架：`那时候…也不…，也不会在…，也不会在…，那时候…`。内容必须是真实的身体感受与家人近况类怀旧素材（由用户提供）。**唯一被复盘语料支持的排比形态**；其余场景禁排比——课程语域另有 B19 的枚举例外。

### B15 给事物起绰号
给公司、物件起昵称并全篇沿用（含反讽式命名，如把裁员补偿叫"毕业大礼包"——该词已入词库）。写新文本时：**只能用用户本次提供的绰号，禁止搬语料旧绰号**（旧绰号指向真实雇主与地点）。

### B16 生活化类比教学（课程主装置）
入口词：`就像`（课31）/ `好比` / `打个比方` / `相当于` / `你可以把它理解为`。类比对象取日常物件与场景：积木、流水线、图书馆、做菜、学开车、新同事与实习生、指挥与兵种。**一个概念配一个类比讲透，不换着比喻堆**。影视剧类比是真实习惯，但剧名与角色名只能来自用户本次素材。

### B17 概念三步落地（课程主装置）
新概念的固定推进：一句大白话定义（`简单来说` / `本质上` / `相当于`）→ 一个类比或使用场景 → 直接上代码或操作（`代码如下` / `我们结合例子看一下`）。三步之间不绕弯、不抒情。

### B18 推论链：这意味着 / 这就是 / 这正是（课程语域）
摆完事实后用 `这意味着` 抽一层推论，或用 `这就是 / 这正是` 把段落钉回主旨。一段至多一次，连用=AI 腔。

### B19 对比枚举：有的…有的…也有的（课程语域，替代排比的合法形态）
枚举同类事物的分化用 `有的…有的…也有的…` 铺陈，随后**必须落一个自己的判断**把它们收拢（指出它们共同在解决/回避什么）。铺陈不判断=平台平均稿。

### B20 亲历背书（课程语域的可信度装置）
讲到坑与选型时插一句自己付出的真实代价：时间、版本号、失败次数。**代价必须来自用户提供的真实素材，不得编造**。形态："这个坑我花了 X 才解决"式的一句带过，不展开成故事。

## D 反装置（按语域禁用；写了就不像）

**全语域禁**：
- **金句收束**："真正的 X 从来不是 Y"这类可摘抄句，全部语料零出现（课程的"一句话总结"是收纳信息，不是造格言）。
- **三字五字 staccato 碎句排**、**每句一段的碎段**。
- **段首空话**："毫不夸张地说""某种意义上""有趣的是"零出现。
- **"让我们共同/一起见证/期待"式升华**。

**手写体语域禁（技术博客 / 复盘 / 水族），课程语域放开**：
- 破折号"——"（手写体≈0，课B 102/万字）
- "让我们"（课43 次，手写体 0 次）
- "不是 A，而是 B"（手写体 8 万字仅 3 次，课程 110 次——博客复盘一段至多 1 次已是上限）
- "意味着"推论（手写体仅技术文 6 次）
- 关键短语加粗（课程版式，手写体无）
- "记住："冒号悬念、"一句话总结"（课B 专用）

**课程语域禁（主语料零出现）**：
- 呵呵 / ^_^ / ~~~ / ！！！（水族专属）
- 黑科技 / 杀手锏 / 说人话 / 接地气 / 大白话 / 玩转（候选全 0）
- 复盘感怀串（平安喜乐 / 辗转反侧……）
- 升华式结尾、贩卖焦虑式设问（"你还不学就晚了"类零出现）
