## 二、复用了已有手法、只作强化不重复立条

- **删次要坑**：AI 列了两个坑（假 iPhone EXIF + 尺寸），liulei **删掉 EXIF 整段**，只留尺寸 + 批量。→ 复用手法 12 / §6.4「砍到最痛，不为全面凑数量」。
- **承认边界**："走 API key 我没找过渠道，不知道大批量成本，因此这里我没有啥发言权。"→ 复用手法 7 / §2⑤。签名句"没啥发言权"可入词库。
- **结尾不升华**：AI 有个"## 说到底…真正救我的是两次把问题问对"的顿悟回环，liulei **整段删**，落在"工具顺不顺手看你站哪儿干活"的适用边界收尾。→ 复用手法 8 / §6.2。
