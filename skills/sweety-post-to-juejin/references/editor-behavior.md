# 掘金编辑器行为

默认入口：

`https://juejin.cn/editor/drafts/new`

执行顺序：

1. 等待标题输入框和 Markdown 编辑器出现。
2. 填标题。
3. 将 Markdown 写入 CodeMirror、textarea 或 contenteditable 编辑器；纯文本输入需先经过保守 Markdown 排版。
4. 点击发布入口打开发布设置。
5. 填简介。
6. 选择分类和标签。
7. 上传封面。
8. 默认停止，等待用户人工审核。

验证重点：

- 标题真正写入。
- Markdown 编辑器可见且有内容。
- 发布设置面板打开。
- 简介、分类、标签必须能回读验证。
- 如果用户提供封面，封面必须能确认上传成功；不能仅检查文件选择控件被点击。

不要依赖固定等待时间作为唯一判断；固定等待只作为 DOM 状态变化后的短暂缓冲。
